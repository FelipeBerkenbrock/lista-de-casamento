#LISTA DE CASAMENTO

#SOBRE O PROJETO

#Este é um projeto de website simples para uma lista de presentes de casamento que eu e minha noiva utilizamos em nosso convite de casamento.

#Eu aproveitei a oportunidade de precisarmos de um website para uma "lista divertida de presentes de casamento" para não só economizar nas taxas de websites famosos mas também usar a experiência como um projeto pessoal de aprendizado de conceitos básicos de construção de interfaces web e organização de arquivos para criação do website.

#Utilizei o github pages como repositório dos arquivos para hospedar o website, não apenas pela gratuidade, como também pelo fato de que o website não irá requisitar ou expor nenhum dado sensível.
